1How to read this

Every model below is served by the local Our Free Model gateway with no login and no API key. The rank is the picker order: a practical blend of capability ceiling, context/output size and measured latency — it is guidance for picking a model fast, not a benchmark result. Free lanes rotate: when one model returns 429/503, the combo or a router covers the same request.

Lane meaning. free = OpenCode Zen free lane (frontier models, large injected system prompt ≈ 5.6–6.4k tokens per request). kilo = Kilo AI's keyless isFree pool (≈2k tokens overhead; prompts may be logged upstream). combo = a local failover chain, not a model. Vision = accepts images. Out = max output tokens — the column that quietly matters most for big rewrites and document generation.

Reading the numbers. Free-lane models are fastest but carry a large injected system prompt (that's the cost of keyless frontier access); Kilo lanes are leaner; FCC via OpenRouter is the leanest and slowest. A one-line question costs ~5.9k tokens on the free lane — for cost-sensitive bulk work prefer 24/25/27 or the fcc provider.

Ranking caveat. These are latency and size facts plus practical fit. No benchmark scores are implied; upstream rosters change and quotas rotate. Re-run npm run bakeoff any time for a fresh scorecard.

5Using them in OpenCode

  • Select: /models → provider ofm → NN-name. The numbers are the ranking.
  • Refresh the roster after upstream changes: npm run sync (re-pulls live models, keeps this order).
  • Reorder the top: edit the PRIORITY array in bin/sync-models.mjs, then npm run sync. Unlisted new models append alphabetically — nothing disappears.
  • Privacy: Kilo-lane prompts may be logged upstream; route anything sensitive through your own aggregate keys (dashboard → Aggregate) or local Ollama via the fcc provider.
  • More lanes (dashboard at http://127.0.0.1:18900): EAC (GitHub sign-in + star) and account channels (LobsterAI, Qoder, TRAE, Cline, Loomy, Raccoon, MiniMax Code, ZCode, Gemini) add models after you sign in.
