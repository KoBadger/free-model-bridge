# Model notes — all 22 free models

Everything below is served by the local gateway with **no login and no API key**, exposed in OpenCode as provider **`00-free`**, in the order `00`–`21` (the number is the picker order). The same order, names and role tags are generated by `npm run sync`; the PDF version of this guide with the ranked table is [`model-guide.pdf`](model-guide.pdf). Regenerate both with `npm run guide` after the roster changes.

**Lanes.** `free` = OpenCode Zen free lane (frontier models; ~5.6–6.4k tokens of injected system prompt per request). `kilo` = Kilo AI's keyless *isFree* pool (~2k overhead; **prompts may be logged upstream**). `combo` = a local failover chain, not a model.

**On the ranking.** It's practical guidance — capability ceiling, context/output size and measured latency — not benchmark scores. Re-run `npm run bakeoff` for a fresh latency scorecard, and `npm run sync` when the upstream roster changes.

**Provenance and setup** are covered in sections 7 and 8 of the PDF.

## 00 · Auto Combo — `combo:recommended-free`
`combo lane · 1M ctx · 131k out · vision`

**Excels at** never being the bottleneck: it chains several free links and only moves to the next one when a link fails *before producing any content*.
**Use it for** unattended or long jobs where a 429 mid-run shouldn't kill the session, and as the "don't make me think" default.
**Watch** that you inherit the head link's latency and its prompt overhead.

## 01 · DeepSeek V4.1 Flash — `deepseek-v4.1-flash-free`
`free lane · 1M ctx · 384k out · vision`

**Excels at** broad competence — reasoning, coding, tool use — with the **largest output budget in the stack** (384k).
**Use it for** your main driver: real coding sessions, whole-file writes, long explanations, multi-step agent work.
**Watch** the ~5.9k-token free-lane system prompt on tiny one-shots, and shared quota at busy hours.

## 02 · GLM 5.3 Flash — `glm-5.3-flash-free`
`free lane · 1M ctx · 131k out · vision`

**Excels at** quick, well-structured reasoning with strong multilingual coverage and vision.
**Use it for** a second opinion on 01, translation and multilingual docs, and fast reviews of screenshots or diagrams.
**Watch** that it's a flash-tier model: great judgment per second, less depth on very hard problems.

## 03 · MiMo V2.6 Flash — `mimo-v2.6-flash-free`
`free lane · 1M ctx · 131k out · vision`

**Excels at** mixed text + image conversations at a balanced speed/quality point.
**Use it for** UI iteration, reading screenshots into notes, and everyday multimodal chat.
**Watch** that it's a generalist — for dense charts lean on 04.

## 04 · Nemotron 3.5 Super VL — `nemotron-3.5-super-vl-free`
`free lane · 1M ctx · 131k out · vision`

**Excels at** actually *reading* images: dense charts, tables, UI screenshots, OCR-ish extraction.
**Use it for** "what does this graph say", screenshot → bug report, diagram → spec, invoice/receipt parsing.
**Watch** output length: it's a describer, not a novelist.

## 05 · Nemotron 3.5 Lightning — `nemotron-3.5-lightning-free`
`free lane · 128k ctx · 32k out`

**Excels at** response speed on short context — the quickest free-lane feel.
**Use it for** fast chat, small edits, tight tool loops, quick sanity checks.
**Watch** the 128k context: long logs and whole-repo reads belong elsewhere.

## 06 · Kilo Auto — `kilo-auto/free`
`kilo lane · 256k ctx · 32k out`

**Excels at** routing inside Kilo's free pool automatically, with the leanest Kilo-side overhead.
**Use it for** a hands-off default on the Kilo lane when you don't care which model answers.
**Watch** that you get whichever model it picks — prompts may be logged upstream.

## 07 · Nemotron 3 Ultra 550B — `nvidia/nemotron-3-ultra-550b-a55b:free`
`kilo lane · 1M ctx · 65k out`

**Excels at** the heaviest reasoning available here — planning, proofs, gnarly debugging.
**Use it for** architecture decisions, postmortems, hard algorithm work, "why is this test flaky" investigations.
**Watch** latency: it's the slowest lane. Don't use it for bulk churn.

## 08 · Nemotron 3.5 Super VL (Kilo) — `nvidia/nemotron-3.5-super-vl:free`
`kilo lane · 1M ctx · 131k out · vision`

**Excels at** the same careful vision work as 04, without the Zen-lane prompt overhead.
**Use it for** image-heavy work when the free lane is throttled, or when you're cost-sensitive about prompt tokens.
**Watch** that Kilo's free pool can rotate models underneath the id.

## 09 · Nemotron 3.5 Lightning (Kilo) — `nvidia/nemotron-3.5-lightning:free`
`kilo lane · 1M ctx · 65k out`

**Excels at** speed at 1M context — rare combination.
**Use it for** first-pass triage of huge logs, diffs or transcripts, then hand the finding to a deeper model.
